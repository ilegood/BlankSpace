# 🌌 Blankspace (블랭크스페이스)

> **게임 창작자를 위한 웹 기반 워크스페이스 및 프로젝트 관리·기획 도구**

Blankspace는 게임 개발 과정에서 파편화되기 쉬운 세계관, 캐릭터 설정, 시스템 기획, 레퍼런스, 데이터 시트, 플로우차트 등을 한곳에서 체계적으로 관리할 수 있는 게임 창작 특화 웹 워크스페이스입니다.

---

## 🎨 디자인 콘셉트
- **Minimal White & Soft Lavender** 기반의 깨끗하고 직관적인 인터페이스
- 창작 작업에 집중할 수 있는 넉넉한 여백과 일관된 시각 계층
- 모든 텍스트 입력창은 순수한 흰색 배경으로 통일하여 최상의 가독성 제공

---

## ✨ 주요 기능

### 1. 홈 대시보드 & 계층형 워크스페이스
- **홈 화면 (`HomeView`)**: 진행 중인 게임 프로젝트들을 한눈에 확인하고 생성
- **다단계 폴더 중첩**: 무제한 폴더 생성 및 순환 참조 방지 드래그 앤 드롭 이동
- **커스텀 정렬 모드**: 드래그로 원하는 순서를 지정하는 `사용자 지정 순서`, `수정일순`, `생성일순`, `이름순` 정렬 지원 (새로고침 후에도 저장)

### 2. 공통 문서 편집기 & 다중 페이지
- **WYSIWYG 리치 텍스트**: Tiptap 기반 제목(H1~H3), 체크리스트, 인용문, 표(3x3), 구분선 등
- **다중 페이지 시스템**: 문서 하나에 여러 챕터/페이지를 분리하여 정리
- **무손실 자동 저장**: 500ms 디바운스 자동 저장 및 페이지 전환/창 닫기 시 즉시 저장 보장
- **내부 링크 & 백링크**: 문서/페이지 간 뱃지형 링크 점프 및 실시간 역방향 백링크 패널

### 3. 게임 창작 특화 편집기 (Special Editors)
1. **캐릭터 관계도 (`character-relations`)**: 원형 초상화 프로필 노드, 양끝 감정 그라데이션 관계선, 특정 캐릭터 관점의 관계 인스펙터
2. **세계관 지도 (`world-map-factions`)**: 대륙 지도 줌/팬, 국가/지역/세력 핀 마커 배치, 관련 기획 문서 원클릭 점프
3. **게임 플로우차트 (`game-flow`)**: 시작, 스토리 씬, 선택지 분기, 전투/이벤트, 엔딩 노드 그래프 및 조건 라벨 연결선
4. **아이템 & 장비 시트 (`game-items-equip`)**: 테이블 표/카드 그리드 뷰, 6단계 등급, 동적 Key-Value 스탯 편집기
5. **모션 애니메이션 시트 (`design-animation-sheet`)**: 프레임 타임라인, 루프 재생, 1~30 FPS 조절 및 실시간 캔버스 프리뷰
6. **사운드 보드 (`design-sound-board`)**: BGM, SFX, 보이스, 환경음 관리, 실시간 탐색 시크바 및 인게임 연출 트리거 기록

### 4. 미디어 첨부 & 결과물 이미지 내보내기
- **미디어 첨부 모달**: 이미지/GIF (로컬 파일 업로드 및 URL), YouTube 16:9 반응형 플레이어, 비디오/오디오 플레이어, 외부 웹 링크 카드
- **고해상도 이미지 내보내기**: 작성한 문서 및 특수 편집기(관계도, 지도, 플로우차트, 시트 등)를 2배율 Retina PNG 이미지로 원클릭 다운로드

### 5. 전역 통합 검색 (`Ctrl + K`)
- 키보드 단축키 `Ctrl + K` (또는 Mac의 `Cmd + K`)로 언제든 커맨드 팔레트 호출
- 프로젝트, 폴더, 문서, 페이지 본문 내용까지 실시간 탐색 및 키보드 방향키 이동

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Rich Text Editor**: Tiptap (`@tiptap/react`, StarterKit, Table, TaskList, Youtube 등)
- **Node Graph**: `@xyflow/react` (React Flow)
- **Icons**: Lucide React
- **Export**: `html-to-image`
- **Storage**: IndexedDB (`idb-keyval`) & LocalStorage fallback

## 🚀 시작하기

### 1. 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```
