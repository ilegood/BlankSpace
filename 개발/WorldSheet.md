# Blankspace - 세계관 시트(World Sheet) 신규 개발

## 1. 개발 목표

Blankspace의 세계관 카테고리에 '세계관 시트(World Sheet)' 템플릿을 개발한다.

이번 템플릿은 기존에 구현된 **캐릭터 시트의 컴포넌트 기반 편집 시스템을 그대로 재사용**하는 것이 핵심이다.

새로운 편집기나 별도의 커스터마이징 시스템을 개발하지 않는다.

캐릭터 시트와 동일한 편집 방식, UI 구조, 기능, 저장 시스템을 사용하되, 내부에 제공되는 기본 컴포넌트와 입력 항목, 예시 데이터만 세계관 정리에 적합하도록 변경한다.

즉, 캐릭터 시트와 세계관 시트는 동일한 편집 시스템을 공유하는 서로 다른 템플릿이다.

---

## 2. 캐릭터 시트와 공유해야 하는 기능

다음 기능은 기존 캐릭터 시트와 동일하게 구현한다.

### 컴포넌트 편집
- 컴포넌트 추가 및 삭제
- 컴포넌트 이름 변경
- 컴포넌트 순서 변경
- 드래그를 통한 위치 변경
- 크기 조절
- 컴포넌트별 속성 편집
- 내부 필드 추가 및 삭제
- 내부 필드 이름 변경
- 입력 유형 변경
- 텍스트 및 이미지 편집

### 디자인 커스터마이징
- 카드 배경색 변경
- 글자 색상 및 크기 변경
- 글꼴 변경
- 테두리 및 모서리 스타일 변경
- 카드 간격 및 배치 조절
- 단색, 그라데이션, 간단한 패턴 지원
- 다크 모드 지원

### 사용자 정의 템플릿
- 사용자가 직접 구성한 세계관 시트 구조 저장
- 사용자 정의 템플릿 이름 변경
- 복제 및 삭제
- 저장한 템플릿 불러오기
- 실제 세계관 내용과 템플릿 구조 분리

사용자 정의 템플릿에는 컴포넌트 구성과 필드 구조, 디자인 설정만 저장한다.

실제 세계관 이름, 설명, 이미지 등 작성된 콘텐츠는 저장하지 않는다.

### 보기 모드와 편집 모드
기존 캐릭터 시트의 보기 모드와 편집 모드 규칙을 그대로 따른다.

- 보기 모드에서는 콘텐츠를 읽기만 할 수 있다.
- 편집 모드에서만 콘텐츠와 컴포넌트를 수정할 수 있다.
- 보기 모드에서는 실제 데이터 변경 동작을 차단한다.

## 3. 세계관 시트 기본 컴포넌트

세계관 시트에는 세계관 정보를 정리하기 위한 기본 컴포넌트를 제공한다.

아래 항목은 기본 구성 예시이며, 사용자가 자유롭게 추가하거나 삭제하고 수정할 수 있어야 한다.

### 3-1. 세계관 대표 이미지
- 세계관을 대표하는 이미지
- 배경 이미지 또는 컨셉 아트
- 이미지 크기 및 비율 조절
- 이미지 설명 추가

### 3-2. 세계관 기본 정보 카드

기본 필드:
- 세계관 이름
- 영문 이름
- 한 줄 소개
- 장르
- 시대적 배경
- 세계의 규모
- 주요 키워드

### 3-3. 세계관 개요 카드

세계관 전체를 소개하는 상세 설명 영역이다.

예시:
- 세계관의 전체적인 설정
- 세계의 분위기
- 핵심 콘셉트
- 주요 특징

### 3-4. 역사 및 배경 카드

세계가 형성된 배경과 주요 역사를 기록한다.

예시:
- 세계의 기원
- 주요 역사적 사건
- 문명의 발전
- 현재 시대의 상황

### 3-5. 세계의 구조 카드

세계의 구성과 공간적 특징을 정리한다.

예시:
- 차원 및 공간
- 지역 구성
- 자연환경
- 기후
- 주요 지형

### 3-6. 종족 및 생명체 카드

세계관에 존재하는 종족과 생명체를 정리한다.

예시:
- 종족 이름
- 외형적 특징
- 생태
- 능력
- 사회적 특징

### 3-7. 사회 및 문화 카드

세계관 속 사회와 문화를 정리한다.

예시:
- 국가와 세력
- 정치 체계
- 종교
- 문화와 관습
- 경제 및 산업
- 기술 수준

### 3-8. 세계의 규칙 카드

세계관이 작동하는 기본 규칙을 정리한다.

예시:
- 물리적 법칙
- 마법 및 초자연적 현상
- 기술적 제약
- 금기와 제한
- 죽음과 생명에 관한 규칙

### 3-9. 태그 및 키워드 카드

세계관을 대표하는 키워드를 정리한다.

예시:
- 다크 판타지
- 중세
- 포스트 아포칼립스
- 마법
- 몬스터
- 스팀펑크

태그의 색상과 이름을 수정할 수 있도록 한다.

### 3-10. 자유 메모 카드

세계관에 관한 추가적인 아이디어나 미정 설정을 자유롭게 기록한다.

---

## 4. 컴포넌트 설계 원칙

위에 제시한 기본 컴포넌트를 모두 고정된 양식으로 만들지 않는다.

사용자가 각 컴포넌트의 내부 필드를 자유롭게 변경할 수 있어야 한다.

예를 들어 세계관 기본 정보 카드에서 다음 작업이 가능해야 한다.

- '장르' 필드 삭제
- '마법 체계' 필드 추가
- '시대적 배경'을 '현재 연도'로 변경
- 필드 순서 변경
- 필드 입력 유형 변경

세계관 개요 카드 역시 사용자가 원하는 제목과 설명 영역으로 변경할 수 있어야 한다.

캐릭터 시트에서 이미 지원하는 컴포넌트 편집 방식과 일관성을 유지한다.

단, 세계관 시트에 적합하지 않은 캐릭터 전용 기능을 무리하게 가져오지 않는다.

---

## 5. 디자인 방향

세계관 시트는 캐릭터 시트와 동일한 UI 시스템을 사용한다.

기존 Blankspace의 전체 디자인과 편집 인터페이스를 유지한다.

세계관 시트만을 위한 별도의 UI를 임의로 만들지 않는다.

기본 예시 데이터는 사용자가 세계관 시트의 목적을 쉽게 이해할 수 있도록 구성한다.

대표 이미지와 정보 카드, 상세 설명 카드가 조화롭게 배치되도록 한다.

세계관마다 필요한 정보가 다르므로 기본 구성은 유용한 출발점이어야 하며, 사용자가 자유롭게 변경할 수 있어야 한다.

---

## 6. 데이터 및 저장 시스템

- 기존 Blankspace의 공통 저장 시스템을 사용한다.
- 기존 캐릭터 시트의 저장 구조와 호환성을 확인한다.
- 세계관 시트의 콘텐츠 데이터와 템플릿 구조를 분리한다.
- 사용자 정의 세계관 템플릿은 별도로 저장한다.
- 새로고침 후 데이터가 유지되어야 한다.
- 저장 실패 시 실제 실패 상태를 표시한다.
- 기존 캐릭터 시트 및 다른 문서의 데이터에 영향을 주지 않는다.
- 기존 사용자 문서와 콘텐츠를 삭제하거나 초기화하지 않는다.

기존 코드 구조를 먼저 분석하고, 캐릭터 시트의 컴포넌트 편집 시스템을 재사용할 수 있는 방법을 확인한다.

불필요하게 동일한 기능을 중복 개발하지 않는다.

## 7. 작업 진행 순서

이번 작업은 세계관 시트의 신규 개발이다.

다음 순서를 반드시 지킨다.

### Phase 0. 기존 시스템 분석
- 캐릭터 시트의 컴포넌트 구조 분석
- 편집 기능과 저장 구조 분석
- 사용자 정의 템플릿 저장 방식 분석
- 세계관 시트에서 재사용할 수 있는 기능 확인
- 기존 데이터에 영향을 주지 않는 구현 방식 결정

분석 결과를 먼저 보고한다.

### Phase 1. UI 구현
- 세계관 시트 기본 UI 구현
- 기본 컴포넌트 구성
- 세계관 예시 데이터 배치
- 캐릭터 시트와 동일한 편집 UI 적용
- 다크 모드 확인

이 단계에서는 실제 기능을 한꺼번에 구현하지 않는다.

UI 구현이 완료되면 사용자에게 검토를 요청하고 승인을 기다린다.

### Phase 2. 기능 구현
UI 승인 후 다음 기능을 구현한다.

- 컴포넌트 추가 및 삭제
- 컴포넌트 이동 및 크기 조절
- 필드 추가 및 삭제
- 필드 이름 및 입력 유형 변경
- 디자인 커스터마이징
- 사용자 정의 템플릿 저장 및 불러오기
- 보기 모드 및 편집 모드

### Phase 3. 저장 및 데이터 검증
- 콘텐츠 저장 확인
- 템플릿 구조 저장 확인
- 새로고침 후 데이터 유지 확인
- 사용자 정의 템플릿 재사용 확인
- 기존 캐릭터 시트 데이터 보존 확인

### Phase 4. 도움말 및 테스트
- 실제 구현된 기능에 맞춰 도움말 작성
- 모든 주요 기능 브라우저 테스트
- 다크 모드 테스트
- 기존 템플릿 회귀 테스트

각 Phase가 완료될 때마다 결과를 보고하고 사용자의 확인을 기다린다.
