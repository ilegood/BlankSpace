    12. **인용문 카드 (`quote-card`)**: 인용문 본문 및 출처/화자 편집.
    13. **동영상 카드 (`video-card`)**: 동영상 파일 업로드 또는 URL 입력 및 실제 `<video controls>` 재생.
    14. **오디오 카드 (`audio-card`)**: 오디오 파일 업로드 시 실제 재생 길이(`M:SS`) 자동 추출 및 재생/일시정지 토글.
    15. **메모 카드 (`memo-card`)**: 자유 메모 텍스트 편집.

## 5. 테스트 시 참고 및 주의사항 (잠재적 이슈 / 확인 포인트)

1. **브라우저 로컬 스토리지(`localStorage`) 기존 데이터와의 호환성**
   - 이전에 생성해 둔 문서나 컴포넌트는 `localStorage`에 예전 초기 데이터 구조로 저장되어 있을 수 있습니다.
   - 코드에서 구버전 데이터도 안전하게 폴백(fallback)되도록 방어 로직을 넣어두었으나, **새로 추가된 기본값이나 변경된 레이아웃(예: 대화 스크립트의 수동 연결선, 빈 문서의 기본 설명 제거 등)을 가장 정확하게 확인하시려면 새 문서를 생성해서 테스트**하시는 것을 권장합니다.
2. **오디오 / 비디오 / 고해상도 이미지 업로드 용량**
   - 현재 서버 없이 브라우저 `localStorage`에 Base64 Data URL 형태로 저장되는 구조이므로, 수십 MB 이상의 대용량 동영상이나 고음질 WAV 파일을 여러 개 업로드하면 브라우저 스토리지 쿼터(약 5~10MB) 제한에 걸릴 수 있습니다. 테스트 시에는 가벼운 이미지나 짧은 MP3/MP4 클립 사용을 권장합니다.
3. **빈 문서(`BlankDocumentEditor`)의 링크 칩 및 표 동작**
   - 링크는 `user-select: all` 스타일이 적용된 버튼형 칩으로 삽입되어 클릭 시 이동(보기 모드 및 내부 문서 링크)하고, 편집 모드에서 백스페이스로 한 번에 지울 수 있습니다.
   - 커서가 표 내부 셀에 위치할 때는 상단 툴바의 `표 ▾` 버튼이 자동으로 `표 편집 ▾`으로 바뀌어 표 내부에 또 다른 표가 중첩 생성되는 현상을 방지합니다.
