# Blankspace - 캐릭터 문답 템플릿 신규 개발

## 1. 개발 목표

Blankspace의 캐릭터 카테고리에 새로운 문서 템플릿인 '캐릭터 문답'을 개발한다.

캐릭터에게 다양한 질문을 제시하고, 해당 캐릭터가 어떤 답변을 할지 작성하는 문답형 문서다.

이 템플릿은 복잡한 대사 스크립트 편집기가 아니다.

기본적인 문서 구조는 다음과 같이 단순하게 유지한다.

**Q. 질문 내용**

A. 답변 내용

**Q. 질문 내용**

A. 답변 내용

위 구조를 반복하는 방식으로 구성한다.

가장 중요한 기능은 사용자가 직접 작성한 질문 목록을 프리셋으로 저장하고, 다른 캐릭터 문답 문서에서도 재사용할 수 있도록 하는 것이다.

---

## 2. 기본 문서 UI

### 2-1. 문서 구성

- 문서 제목
- 질문과 답변 목록
- 질문 추가 버튼
- 질문 순서 변경 기능
- 질문 삭제 기능

각 문답 항목은 Q와 A가 하나의 묶음으로 구성된다.

**Q 영역**
- 질문 내용을 입력하는 텍스트 영역
- 질문 내용 수정 가능
- 질문 삭제 기능
- 질문 순서 변경 기능

**A 영역**
- 질문에 대한 답변을 입력하는 텍스트 영역
- 여러 줄 입력 지원
- 답변 내용 자동 저장

Q와 A는 시각적으로 명확하게 구분한다.

질문 번호를 자동으로 표시할 수 있도록 한다.

예시:

Q1. 가장 좋아하는 음식은?

A. 따뜻한 수프를 좋아한다.

Q2. 가장 싫어하는 사람 유형은?

A. 거짓말을 밥 먹듯이 하는 사람.

Q3. 휴일에는 무엇을 하나요?

A. 집에서 책을 읽거나 낮잠을 잔다.

질문이 추가되거나 삭제되면 번호가 자동으로 갱신되어야 한다.

### 2-2. 질문 관리

- 질문 추가
- 질문 수정
- 질문 삭제
- 질문 순서 변경
- 질문 복제
- 질문 목록 전체 비우기

질문을 추가하면 새로운 Q/A 항목이 생성된다.

질문을 삭제하면 해당 질문과 답변이 함께 삭제되므로 삭제 전에 확인을 요청한다.

질문 순서를 변경해도 해당 질문에 작성한 답변은 함께 이동해야 한다.

## 3. 질문 프리셋 시스템

이번 템플릿의 핵심 기능이다.

사용자가 작성한 질문 목록만 별도로 저장하여 다른 캐릭터 문답 문서에서 재사용할 수 있도록 한다.

### 3-1. 프리셋 저장

문서에 작성된 질문들을 하나의 프리셋으로 저장할 수 있도록 한다.

저장할 때 프리셋 이름을 입력한다.

예시:
- 기본 캐릭터 질문
- 성격 파악 질문
- 일상 관련 질문
- 연애 관련 질문
- 과거 및 배경 질문
- 직접 만든 질문 모음

프리셋에는 다음 정보만 저장한다.

- 프리셋 이름
- 질문 목록
- 질문 순서
- 생성일 및 수정일

**중요: 답변 내용은 프리셋에 저장하지 않는다.**

캐릭터 이름, 캐릭터 정보, 기존 문서 내용도 저장하지 않는다.

### 3-2. 프리셋 불러오기

문서 상단에 '질문 프리셋' 버튼을 배치한다.

버튼을 클릭하면 저장된 프리셋 목록이 표시된다.

프리셋을 선택하면 해당 질문 목록을 현재 문서에 적용한다.

불러온 질문에는 모두 빈 답변 영역이 생성되어야 한다.

이미 작성한 문답이 있는 상태에서 프리셋을 불러오면 기존 질문과 답변을 덮어쓸 수 있으므로 반드시 확인 메시지를 표시한다.

다음 두 가지 적용 방식을 지원한다.

1. 전체 교체: 기존 질문 목록을 제거하고 선택한 프리셋의 질문으로 교체한다.
2. 질문 추가: 기존 질문은 유지하고 프리셋의 질문을 마지막에 추가한다.

질문 추가 방식에서는 기존 답변을 절대 변경하거나 삭제하지 않는다.

### 3-3. 프리셋 관리

별도의 프리셋 관리 UI를 제공한다.

지원 기능:
- 프리셋 저장
- 프리셋 이름 변경
- 프리셋 복제
- 프리셋 삭제
- 프리셋 불러오기

프리셋을 삭제해도 해당 프리셋을 사용해 이미 생성한 문서에는 영향을 주지 않아야 한다.

프리셋 목록은 사용자가 쉽게 확인하고 관리할 수 있도록 간결하게 구성한다.

## 4. UI 디자인 방향

전체적인 디자인은 Blankspace의 기존 UI 시스템을 유지한다.

캐릭터 문답은 복잡한 편집 도구가 아닌 읽기 쉽고 편안한 문서 형태로 디자인한다.

### 상단 영역
- 문서 제목
- 질문 프리셋 불러오기
- 현재 질문 목록을 프리셋으로 저장
- 보기 모드 / 편집 모드 전환

### 본문 영역
- Q/A 문답 목록
- 질문 추가 버튼
- 질문 순서 변경
- 질문별 삭제 및 복제

### 프리셋 관리 UI
- 저장된 프리셋 목록
- 프리셋 이름
- 불러오기
- 이름 변경
- 복제
- 삭제

불필요한 카드나 장식 요소를 과도하게 추가하지 않는다.

Q와 A의 구분이 명확하고 여러 문답을 연속해서 읽기 편한 구조를 우선한다.

다크 모드에서도 텍스트와 입력 영역의 가독성을 유지한다.

## 5. 보기 모드와 편집 모드

Blankspace의 공통 템플릿 동작 규칙을 준수한다.

**보기 모드**
- 질문과 답변을 읽을 수 있다.
- 질문 추가, 삭제, 수정 불가능
- 답변 수정 불가능
- 질문 순서 변경 불가능

**편집 모드**
- 질문과 답변 수정 가능
- 질문 추가 및 삭제 가능
- 질문 순서 변경 가능
- 질문 프리셋 저장 및 불러오기 가능

보기 모드에서는 UI 버튼만 숨기는 것이 아니라 실제 데이터 변경 동작도 차단해야 한다.

---

## 6. 데이터 저장 및 안정성

- 기존 Blankspace의 공통 저장 시스템을 사용한다.
- 질문과 답변은 문서별로 독립적으로 저장한다.
- 프리셋은 문서 데이터와 별도로 관리한다.
- 프리셋은 여러 캐릭터 문서에서 재사용할 수 있어야 한다.
- 새로고침 후 질문과 답변이 유지되어야 한다.
- 프리셋도 새로고침 후 유지되어야 한다.
- 프리셋 불러오기가 기존 문서 데이터를 실수로 손상시키지 않도록 한다.
- 저장 실패 시 실제 실패 상태를 사용자에게 알린다.
- 기존 문서 및 사용자 데이터에 영향을 주지 않는다.

기존 IndexedDB 구조와 저장 시스템을 먼저 확인하고, 현재 구조에 적합한 방식으로 구현한다.

## 8. 개발 진행 방식

이번 작업은 신규 캐릭터 문답 템플릿 개발이다.

기존 Blankspace의 전체 UI, 공통 저장 시스템, 다른 템플릿의 동작을 임의로 변경하지 않는다.

다음 순서로 작업한다.

1. 기존 프로젝트 구조와 템플릿 연결 방식 분석
2. 캐릭터 문답 UI 구현
3. UI 구현 완료 후 사용자에게 검토 요청
4. 사용자 승인 후 실제 문답 기능 구현
5. 질문 프리셋 시스템 구현
6. 저장 및 데이터 안정성 테스트
7. 도움말 문서 업데이트
8. 최종 테스트 결과 보고

UI 구현과 기능 구현을 한꺼번에 진행하지 않는다.

각 단계가 완료되면 결과를 보고하고 사용자의 확인을 기다린다.
